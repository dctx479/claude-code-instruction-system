# Evidence examples

The Skill entry defines the current contract. Use this example only when a structured JSON record is requested.

```json
{"command":"python -m unittest discover -s tests","exit_code":1,"output":"actual captured failure output","quality":"unknown: no raw quality measurements"}
```

Concise decision record: date, chosen option, practical reason, observable tradeoff, evidence pointer and active/superseded status. Do not include private deliberation, raw prompts, credentials or fabricated confidence percentages.
