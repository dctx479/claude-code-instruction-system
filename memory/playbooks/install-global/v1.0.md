# install-global v1.0

成功率：尚无观测；由会话反馈统计，不能预填。

1. 查 git status 和目标配置，保留个人改动。
2. 从知识安装根运行 `python scripts/install-global.py --dry-run --target <临时目录>`。
3. 核对 WARNING、components/profile。实际安装只在用户授权的目标进行。
4. 使用 `scripts/verify-global-install.py`，参数与安装保持一致。
5. 需回滚时恢复安装备份中的 settings 和受影响文件；不清理未知或个人文件。

来源：`specs/SPEC-global-install.md`、`scripts/README.md`。
