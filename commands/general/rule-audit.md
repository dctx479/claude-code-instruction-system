## 分类与输出

分类：过期 / 重复 / 可从代码推导 / 模糊 / 应迁移 / 保留 / 需人工确认。
重复并不自动等于可删；先检查加载范围和调用者。无证据不建议删除。

交付：
1. 文件清单（路径、行数、字节数、生效范围、导入关系）。
2. 表格：原文摘要｜分类｜证据｜删/改/挪/留建议｜不确定项。
3. 建议的 unified diff，以及修改前后行数（仅预览，不写回）。
4. 未验证项；明确说明静态检查不等于真实会话加载验证。

完成后停下，不改规则、不 commit、不 push、不开 PR；逐条确认后再应用。
