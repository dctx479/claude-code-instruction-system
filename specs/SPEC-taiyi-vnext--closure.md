# vNext 收尾与真实部署

2026-11-22 · RISK-HIGH · 承接原规格，不改写批准文本。

## 授权与目标

用户要求完成全部修复，并明确选择“同步全局修复并启用调用记录”。提交/正常推送授权沿用。
同步 core、安全 Hook、权限模板与只记工具/名称/时间的本机 90 天记录；不启用自动改写、diff 备份或通知。
未知用途模块保留为非默认可选资产，不把未引用等同于缺陷，不删除历史记忆。

## 实施与验收

1. 修正仍与单一工作流矛盾的 Skill；为全部 core-workflow 提供可执行隔离行为案例，保存实际工具轨迹、产物哈希和命令结果。
2. 真实路由运行完整案例，区分首个选择证据和后续行为完成；超时/预算/无证据不能当成功。
3. 权限边界以无害替身和临时目标验证普通/复合/git -C/PowerShell/default/bypass，以及真实交互提示。未知执行器不宣称覆盖。
4. 安装器补安全迁移与托管备份保留策略；有用户修改或不明来源的目标不移动。修复部分安装/重装不能保留可选记录的行为。
5. 在仓库外实际验证发现和上下文。经已审查计划迁移全局，恢复对应 settings 和能力归档即可回滚。
6. 当前轮 CI 矩阵全绿；交付逐项关闭表。四周观察属于真实日历验收，记录起点与到期日，绝不伪造已观察四周。

## 风险与回滚

真实模型评估只开放所需工具，使用临时配置/仓库和测试身份；不发送通知、不接触生产、不读取用户项目数据。
凭据只在子进程环境中传递，报告不得包含环境值或提示词原文中的私密信息。
迁移采用可回滚归档，禁止未知目录批量删除；设置和源码改动按主题回退。
权限约束不等于 OS 沙箱；任意解释器/编码/外部程序的完全隔离需另行 OS 安全边界，不能靠有限字符串规则保证。
